# FinalProject

Веб-приложение для планирования личных целей и повседневных задач. Проект помогает собирать идеи, расставлять приоритеты и отслеживать прогресс в одном месте.

Планируемые возможности:

- Создание задач и распределение их по проектам.
- Установка сроков и приоритетов.
- Отслеживание выполненных задач и достижения целей.

Проект находится на начальном этапе разработки.
